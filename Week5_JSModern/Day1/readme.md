ES6 — Defined
ES6 (ECMAScript 2015) is the 6th edition of the ECMAScript standard that governs JavaScript, released in June 2015. It was a major update that modernized the language by introducing cleaner syntax and powerful new features — such as let/const, arrow functions, classes, modules, and promises — making JavaScript more structured, readable, and capable of handling large-scale application development. It is considered the baseline of all modern JavaScript.

## Concepts Covered

| Feature         | Description 

`let` & `const`    | Block-scoped variable declarations
Arrow Functions    | Shorter function syntax with lexical `this`
Template Literals  | String interpolation using backticks 
Default Parameters | Fallback values in function parameters
Destructuring      | Unpack values from objects or arrays
