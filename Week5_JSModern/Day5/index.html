Day 2

Arrow Functions — shorter way to write functions

▾

Topics covered: () => {} implicit return single param arrow as callback

// Old way - normal function function add(a, b) { return a + b; } // New way - arrow function (same result, less typing) const add = (a, b) => a + b; // One parameter - brackets not needed const double = num => num * 2; // No parameters - use empty brackets const sayHello = () => "Hello!"; // Arrow function inside .map() let nums = [1, 2, 3]; let result = nums.map(n => n * 10); // [10, 20, 30]

💡 Arrow function: const name = (params) => result 💡 If one line, no need for { } or the word return 💡 One param only: const fn = x => x * 2 💡 No params: const fn = () => "hello"

Day 3

Arrays & Objects — map, filter, reduce, find

▾

Topics covered: .map() .filter() .reduce() .find()

let numbers = [10, 20, 30, 40]; // .map() - transform every item, get a new array let doubled = numbers.map(function(n) { return n * 2; }); // [20, 40, 60, 80] // .filter() - keep only items that pass the test let big = numbers.filter(function(n) { return n > 15; }); // [20, 30, 40] // .reduce() - combine all items into ONE value let total = numbers.reduce(function(sum, n) { return sum + n; }, 0); // 100 // .find() - get the FIRST item that matches let found = numbers.find(function(n) { return n > 25; }); // 30
✏️ Your turn — edit the code and click Run
💡 .map() → changes each item, returns NEW array (same length) 💡 .filter() → keeps items where condition is TRUE 💡 .reduce() → starts from 0, adds each item to sum 💡 .find() → returns only the FIRST match, not an array

Day 4

Destructuring — unpack arrays and objects easily

▾

Topics covered: array destructuring object destructuring rename default value

// Array Destructuring // Old way: let first = colors[0]; let second = colors[1]; // New way - one line: let colors = ["red", "green", "blue"]; let [first, second, third] = colors; // Object Destructuring // Old way: let name = person.name; let age = person.age; // New way - one line: let person = { name: "Ali", age: 20 }; let { name, age } = person; // Default value if property does not exist let { country = "Pakistan" } = person;
