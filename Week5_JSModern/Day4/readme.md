# ES6 — Day 4: Destructuring

Destructuring lets you unpack values from arrays or properties from objects into individual variables in a clean, concise way.

## Concepts Covered

| Feature                            | Description |

Array Destructuring — Basic | Unpack array values into variables |
Array Destructuring — Skip Values | Use comma to skip unwanted items |
Object Destructuring — Basic | Unpack object properties into variables |
Object Destructuring — Default Values | Fallback if property is undefined |
Destructuring in Function Parameters | Unpack directly inside function arguments
