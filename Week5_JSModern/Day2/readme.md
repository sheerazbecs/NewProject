
## DAY2 What are Arrow Functions?

An arrow function is a shorter, cleaner syntax for writing functions in JavaScript, introduced in ES6. Instead of using the `function` keyword, it uses `=>` (the arrow). It makes code more concise and readable, especially for simple, single-purpose functions.
---
## Concepts Covered

|  Concept       | Description |

Basic Syntax     | Replace `function` keyword with `=>`        
Single Parameter | No parentheses needed for one parameter
No Parameters    | Empty `()` required when no parameters 
Multiline        | Use `{}` and `return` for multiple lines 
With Arrays      | Cleaner use inside `.map()`, `.filter()` etc.
